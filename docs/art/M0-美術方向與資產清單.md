版本：0.1｜Owner：建模師／技術美術｜章節：CH01 晨線草原｜關聯：[3D 資產規格](../roles/建模師-3D資產與技術美術規格.md)、[UI 線框](../ui/M0-資訊架構與線框規格.md)

## 1. 晨線草原視覺 brief

情緒是「清晨、重新流動、溫和但不脆弱」。主色為草原青綠與光軌金，敵對／靜滯使用低飽和灰紫；危險預警採高亮暖黃／琥珀，不與 Gate 的稀有藍紫混淆。

形狀語言：玩家採上窄下穩、弧形披風／弓的剪影；友方／回響為圓潤、向上流動；普通敵人為短、偏斜、碎裂輪廓；Boss 為寬大圓冠、明確左右肢體與中央核心。任何 9:16 鏡頭下小於 56px 的物件，不靠細節辨識種類，必靠輪廓與色塊。

## 2. 直式鏡頭可讀性約束

| 項目 | 規則 |
| --- | --- |
| 主角 | 站立高度約 1.7m；畫面高度約 11–14%，不能被披風／武器遮住腳底碰撞點。 |
| 普通敵人 | 高度 0.9–1.4m；與主角的材質明度差至少兩階。 |
| Boss | 高度 3.8–4.5m，中央核心與攻擊 socket 不被頭冠遮蔽。 |
| Gate | Gate 本體和文字區之間留空；不得使用大量透明特效遮住 UI。 |
| 預警 | `Muzzle`、地面標記和 `HitPoint` 位置在正面／俯視都可看見。 |
| HUD 遮罩 | 頂部、底部 UI 區不可放需要瞬時反應的敵人／投射物生成點。 |

## 4. Import 與效能 preset

| 類別 | 設定 |
| --- | --- |
| GLB scale | 1.0，1 Three.js world unit=1m；禁止模型師以 loader scale 修正比例。 |
| Mesh | Read/Write 關閉；Mesh Compression Medium；生成 LOD 依資產規格。 |
| Animation | 30 FPS sampling、root motion 關閉、clip 明確命名。 |
| Texture | Source PNG/TGA；輸出 WebP／KTX2 由 Web asset pipeline 壓縮；不得保留未壓縮 duplicate。 |
| Material | URP Lit／Simple Lit，材質共用；透明材質須標記原因。 |
| GLB | 無外部貼圖遺失、無測試 node／camera／light、asset manifest URL／hash／preload group 完整。 |

## 5. M0 建模驗收

- 所有上述 ID、尺寸、掛點與 M1/M2 交付範圍已固定，可被工程建立 placeholder interface。
- CH01 主角、敵人、Boss 的輪廓在 UI 線框指定可視區不衝突。
- 三角形／材質預算符合 3D 資產規格，未將平衡數值塞入 GLB。
- 原創性檢查完成：形狀、名稱、色彩與參考作品無可辨識重合。
