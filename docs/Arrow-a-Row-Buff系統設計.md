# Arrow a Row Buff 系統設計

## 目標

Gate 用於建立當局 Build；一般小怪死亡後掉落小型 Buff，讓玩家透過走位拾取、逐步強化。Gate 套用完整效果，小型掉落套用相同效果的三分之一，且所有效果保留至下一章。

## 八種 Buff

| ID | 類型 | Gate 完整效果 | 小怪掉落（三分之一） | 實際影響 |
| --- | --- | --- | --- | --- |
| `split_arrow` | 箭矢 | +1 箭矢 | +⅓ 箭矢碎片 | 累積滿 1 後增加一支同時射出的箭。 |
| `power_shot` | 輸出 | 箭傷 +25% | 箭傷 +8% | 乘算提高每發傷害。 |
| `swift_shot` | 投射物 | 箭速 +25% | 箭速 +8% | 提高箭矢前進速度。 |
| `rapid_fire` | 輸出 | 射速 +12% | 射速 +4% | 縮短自動射擊間隔。 |
| `flying_sword` | 飛劍 | 飛劍 +1 | +⅓ 飛劍碎片 | 碎片累積滿 1 後增加一把飛劍。 |
| `vitality` | 生存 | 生命 +20 | 生命 +7 | 同時提高最大生命並回復等量生命。 |

## 生成規則

- 每章有三組 Gate，各組提供兩個不重複的 Buff。
- 前兩組只從五種輸出型 Buff（箭矢、箭傷、箭速、射速、飛劍）抽取，確保開局能直接理解自動射箭與輸出 Build。
- 第三組從全部八種 Buff 抽取，才會出現生命、移速、減傷等生存選項。
- 每次新 Run／進入下一章，都以可重現的偽隨機序列重新產生 Gate；同一組左右不會重複。
- 每隻一般小怪死亡必掉一個 Buff 拾取物，類型從八種 Buff 等機率抽取；拾取物顯示名稱與三分之一數值，抵達角色附近即套用。

## Boss 回響

Boss 擊敗後從以下六種回響不重複隨機抽取三種，玩家選擇一種。回響為完整章節獎勵，與一般小怪掉落 Buff 分開計算。

| ID | 效果 |
| --- | --- |
| `storm_bow` | 箭數 +2 |
| `blade_nexus` | 飛劍 +2 |
| `heartwood` | 最大生命與目前生命 +60 |
| `deadeye` | 箭傷 +50% |
| `gale_heart` | 箭速 +40% |
| `ironbark` | 減傷 +25%，總減傷上限 60% |

## 驗收

- 任一 Gate 僅套用一次，左右僅能擇一。
- 連續六次新 Run 的 Gate 抽樣可覆蓋八種 Buff，且前兩組不出現生存型 Buff。
- 小怪死亡會產生可讀的 Buff 拾取物，並套用三分之一效果。
- 所有 Gate／掉落效果會反映到角色數值，並在跨章時保留。
