# Arrow a Row Buff 系統設計

## 目標

Gate 用於建立當局 Build；一般小怪死亡後掉落小型 Buff，玩家透過走位拾取、逐步強化。Gate 套用完整效果，小怪掉落套用同一效果的三分之一，且效果保留至下一章。

目前玩家的基礎輸出為：箭矢 `0.267` 傷害／箭、自動電擊 `1.667` 傷害／秒／目標。箭矢的距離倍率仍為近距離 `150%`、中距離 `90%`、遠距離 `55%`。

## 生成規則

- 每章有三組 Gate；一般 Gate 提供左右兩個不重複 Buff，第一組開場 Gate 特別提供左／中／右三個不重複 Buff。
- 第一組 Gate 固定提供 `split_arrow`、`cannon_weapon` 與 `lightning_targets`，確保箭數從 0 開始的玩家能在第一個選擇取得主要武器；電擊保留既有 2 個初始鎖定目標。
- 第二組只從輸出／電擊／火砲型 Buff 抽取，第三組從全部十六種 Buff 抽取。
- 每隻一般小怪死亡必掉一個 Buff 拾取物，類型從十六種 Buff 等機率抽取；角色接近時自動拾取並套用三分之一效果。
- Gate 的 Buff 視覺使用燈籠；小怪掉落的地面 Buff 使用 Poly Haven Treasure Chest 寶箱模型。兩者的文字提示均顯示對應能力與數值。
- 每次新 Run／進入下一章，都以可重現的偽隨機序列重新產生 Gate。

## 關卡流程與回響

每章固定執行：

```text
5 波小怪 → 地面掉落 Buff
5 波小怪 → 地面掉落 Buff
5 波小怪 → 地面掉落 Buff
最終回響三選一 → Boss 前 5 秒警示 → Boss
```

前三段只透過小怪死亡掉落的 Buff 拾取物強化；第 15 波完成後才暫停並從 7 種回響池抽出 3 個不重複選項，玩家選擇 1 個後進入 Boss 前警示。回響與一般小怪掉落 Buff 分開計算；回響本身的傷害數值維持目前回響池定義，不套用本次一般 Buff 傷害縮放。

Boss 擊敗後同樣從回響池抽出 3 個不重複選項，玩家選擇 1 個作為章節結算獎勵。

| ID | 效果 |
| --- | --- |
| `storm_bow` | 箭數 +2、箭傷 +40% |
| `lightning_core` | 電擊目標 +1、電擊傷害 +3／秒、電擊距離 +6 |
| `heartwood` | 最大生命與目前生命 +60 |
| `deadeye` | 箭傷 +35% |
| `gale_heart` | 箭速 +40% |
| `ironbark` | 減傷 +40%、最大生命 +30 |
| `enemy_swarm` | 小怪數量加倍 |

## 驗收

- 任一 Gate 僅套用一次，左右僅能擇一。
- 小怪死亡會產生可讀的寶箱拾取物，並套用三分之一效果。
- 人物撞到怪物時，先扣除等同該怪物當前生命值的 HP，再立即擊殺該怪物並產生掉落；吸血依實際造成傷害比例回復。
- 吸血初始值為 0%，只有取得 `life_steal` Buff 後才會回復生命。
- 第 5／10 波完成後不開啟回響，繼續生成小怪並處理地面掉落 Buff。
- 第 15 波完成後只出現一次回響，提供三個不重複候選；確認後進入 Boss 前 5 秒警示，Boss 靠近並停在距離 3 單位。
- 所有 Gate／掉落效果會反映到角色數值，並在跨章時保留。
