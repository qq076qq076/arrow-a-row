# 遊戲世界觀規劃師：世界觀與敘事聖經

版本：0.1｜專案定位：手機直式、輕量 Roguelite 自動跑酷射擊｜原則：原創世界、易讀、服務玩法而非中斷玩法。

## 1. 創作目標與邊界

玩家在每局 4–8 分鐘中應感覺自己從孤身信使成長為能穿越裂界的守護者。世界觀要解釋「自動前行、分岔強化、飛箭、飛劍、夥伴、首領、永久成長」，但劇情文字不可阻擋操作、不可要求閱讀長篇設定。

禁則：不得借用參考遊戲的角色、怪物、地名、文案、視覺符號或故事；不使用血腥、仇恨、政治現實映射；角色外觀須適合目標年齡分級。

## 2. 世界核心（可用版本）

世界名為「織光原野」。古老的光軌曾連接各地，後來被名為「靜滯」的霧潮切斷；每一道斷軌都會扭曲為敵群與失控守衛。玩家是「引線者」，持有會自行尋找裂隙的弧光弓，必須沿光軌前進，從左右分支收集不同性質的「回響」，恢復守門者並重新織回道路。

| 遊戲系統 | 世界內解釋 |
| --- | --- |
| 自動前進 | 弧光弓鎖定下一個裂隙，光軌推動引線者。 |
| 自動射箭 | 弓弦回應附近的靜滯殘響，自動釋放弧光箭。 |
| 岔路 | 兩種回響流匯入不同分支，玩家決定要承接哪一條。 |
| 升級／Build | 回響暫時改寫弓、守護刃與同行靈的共鳴方式。 |
| 死亡／再戰 | 引線者被送回「曙站」，帶回少量可永久修復裝置的晶塵。 |
| Boss | 被靜滯困住、需要擊敗後淨化的「斷軌守門者」。 |

## 3. 章節與情緒曲線

| 章節 | 地點 | 情緒／色彩 | 核心敵意 | Boss 敘事 | 解鎖焦點 |
| --- | --- | --- | --- | --- | --- |
| 1 | 晨線草原 | 明亮青綠、金色 | 迷路的草靈與碎片 | `苔冠守衛`：守護道路卻被霧潮困住 | 弓箭與生存。 |
| 2 | 鏡潮高架 | 靛藍、銀白、反光 | 反射體與飛行碎片 | `映流監督者`：把所有方向折成死路 | 飛劍與穿透。 |
| 3 | 熾心熔庭 | 深紫、琥珀、暖光 | 脈衝甲殼與召喚體 | `爐心巨像`：以過量能量封鎖裂隙 | 夥伴與最終淨化。 |

每章只用三段文字：進場一句、Boss 前一句、Boss 後一句；合計每章不超過 90 個繁中文字。文字顯示於 loading、章節橫幅或結算，絕不蓋住 Gate／彈幕。

## 4. 角色與命名規則

| 類別 | 定義 | 命名規則 |
| --- | --- | --- |
| 主角 | 不預設性別與固定臉部背景，讓玩家代入 | 稱呼「引線者」，不用真名。 |
| 夥伴 | 會跟隨、攻擊並提供 Build 視覺辨識的光靈 | `色彩／材質 + 動物或器物`，如「琥珀羽」、「雲針」。 |
| 飛劍 | 古代守護工具，不是具人格的武器 | `動作 + 刃／環／線`，如「回旋刃」。 |
| 敵人 | 受靜滯干擾的原野器物或生物 | `狀態 + 名詞`，如「凝霧射手」。 |
| Boss | 原本職能 + 被困狀態 | 如「失序的苔冠守衛」。 |
| 能力 | 功能要一眼讀懂，世界觀作副標 | `穿風箭`（弧光回響）。 |

避免：專有名詞堆疊、拉丁拼音、同音近似詞、需要百科才能理解的等級名。每個新詞第一次出現必配功能動詞或圖示。

## 5. 敘事投放規格

| 位置 | 字數 | 類型 | 必含資訊 |
| --- | ---: | --- | --- |
| 主選單 | 20–40 字循環 | 世界近況 | 玩家下一步行動。 |
| 新章開場 | ≤24 字 | 場景情緒 | 新區域與威脅。 |
| Gate | ≤12 字 | 功能文案 | 數值效果優先，世界觀只能副標。 |
| Boss 前 | ≤30 字 | 對峙 | Boss 身分與可被淨化的理由。 |
| Boss 後 | ≤30 字 | 收束 | 恢復了什麼、下一站。 |
| 結算 | ≤40 字 | 鼓勵／提示 | 依死亡原因或新解鎖變化。 |

示例：章 1 Boss 後：「苔冠重新聽見了草原的風。前方的鏡潮高架，仍在等待一條穩定的光線。」

## 6. 文案交付格式

世界觀規劃師交付 `docs/content/localization_narrative.csv`，每列含：`key`、繁中、英文、最大字數、畫面 ID、觸發條件、角色／語氣、是否可重複、備註。不得將文字硬寫在 Prefab 或程式。

英文不是直譯驗收；需保留功能清楚度、語氣與 UI 長度。所有 Gate、Boss、能力與錯誤訊息在交付前過術語表檢查。

## 7. 驗收與協作

世界觀規劃師對以下驗收負責：三章皆有主題、敵人與 Boss 的視覺／功能理由；所有文字符合字數；Gate 數值不被敘事覆蓋；沒有原作可辨識元素；繁中／英文 key 完整。與 UI 設計師共同審閱可讀性，與建模師提供每章 moodboard、形狀語言、禁用元素，與 PM 共同凍結章節內容。
