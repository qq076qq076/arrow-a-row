# M6-ENG-004：怪物清場與遠端生成

狀態：Completed｜角色：工程師｜Milestone：M6 關卡節奏重整｜完成日期：2026-07-30

## 實作

- Boss 被擊敗後不立即進入結算；先保持 `playing`，直到場上怪物全部死亡，或已經跑到玩家身後並離開道路有效區域。
- 場上仍有存活怪物時，HUD 顯示「Boss 已擊敗｜清理剩餘怪物」，避免畫面還有敵人卻顯示已完成。
- 一般小怪波次生成於道路可視最遠端 `z = 64`，不再從畫面中段 `z = 38` 出現；之後沿道路向玩家接近。

## 驗收

- 小怪尚存時，Boss 結算 phase 不得進入 `reward`。
- 小怪死亡或跑出玩家身後的道路有效區域（`z < -2`）後，才可進入 Boss 結算。
- 每個波次的敵人初始 `z` 必須等於 `ENEMY_SPAWN_Z`。
