# M3-ENG-013：箭矢碰撞與穿透 Buff

狀態：Completed｜角色：工程師｜Milestone：M3 系統完成｜完成日期：2026-07-29｜Commit：`工程(M3)：完成箭矢碰撞與穿透Buff`（以 Git history 的最終 hash 為準）

## 輸入

- 使用者需求：初始箭矢命中小怪後不得繼續射向後方目標；新增箭矢穿透 Buff。

## 已完成產出

- 自動射擊改為實際投射物碰撞：箭矢在飛行途中檢查小怪與 Boss，命中後才造成傷害。
- 未持有穿透時，箭矢第一個命中即移除，不會再傷害後方目標。
- 新增第九種 Buff `piercing_arrow`：Gate 提供 `穿透 +1`，小怪掉落提供 `穿透碎片 +⅓`；累積滿一點後每支箭可額外通過一個未命中目標。
- 每支箭記錄已命中目標，防止同一支穿透箭在多幀內重複命中同一個敵人。
- 扇形箭矢會以目前目標為中心瞄準，再以固定角度向左右展開，確保角色位於側邊時仍可命中遠方 Boss。
- 舊 checkpoint 缺少穿透欄位時自動回退至 0 穿透，保持相容。

## 完成標準與證據

- Unit test 覆蓋初始箭 0 穿透、取得 Buff 後新箭具有 1 穿透，以及九種 Buff Gate 抽樣。
- Vitest 5 files / 18 tests、production build、Playwright Chrome／WebKit 6/6 均通過。
