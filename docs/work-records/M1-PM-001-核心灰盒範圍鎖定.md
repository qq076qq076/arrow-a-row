# M1-PM-001：核心灰盒範圍鎖定

狀態：Completed｜角色：PM（暫兼系統／關卡／數值簽核）｜Milestone：M1 核心灰盒｜完成日期：2026-07-28｜Commit：`PM(M1)：鎖定核心灰盒範圍`

## 目標

在手機瀏覽器中交付 60 秒可玩的灰盒 Run，驗證單手拖曳、左右 Gate、自動射擊、敵人、死亡與重新開始是否可理解；不進入 Boss、商店、永久升級或最終美術。

## M1 必做範圍

| 系統 | 內容 | 驗收 |
| --- | --- | --- |
| Run state | `Menu → Playing → Dead → Menu` | 不可重複結算、可重新開始。 |
| Input | Canvas 非 UI 區的單指水平拖曳 | 抬手停下；UI 觸控不移動角色。 |
| 戰鬥 | 自動向前射箭、1 近戰敵、1 遠程敵、HP／死亡 | 玩家不需瞄準即可擊殺。 |
| Gate | 2 組左右雙選、箭數／傷害／治療效果 | 每組只套用一次，HUD 可看見。 |
| UI | HUD、開始、死亡、重開 | 直式 safe area 可讀。 |
| QA | 固定 seed、unit／E2E、Chrome／WebKit viewport | 60 秒流程可重現。 |

## 非範圍

飛劍、夥伴、精英、Boss、Reward 重擲、商店、存檔恢復 UI、GLB 最終模型、完整 PWA 離線 Run、真機效能調校。這些維持在 M2／後續工作包。

## 固定內容

- Run seed：`1001001`。
- Gate 1：左 `+1 箭矢`、右 `最大 HP +25，回復 25`。
- Gate 2：左 `箭傷 +25%`、右 `回復 25 HP`。
- 敵人：3 個近戰跑者、1 個有 0.6 秒預警的遠程射手。
- 灰盒結束：玩家死亡或 60 秒完成；M1 不以通關作為完成條件。

## Gate M1 完成標準

1. 新玩家在 10 秒內能拖曳並選中第一個 Gate。
2. 同一 Gate group 不會套用兩次，重複輸入不改變 stats。
3. 自動射擊、敵人受傷／死亡、HP、死亡和重開全部可運作。
4. 固定 seed、固定輸入下 simulation hash 一致。
5. unit、build、Chrome／WebKit viewport smoke 全通；實機 smoke 由 QA 後續補證。
