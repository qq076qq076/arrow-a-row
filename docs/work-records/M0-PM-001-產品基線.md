## 已完成產出

1. 建立本資料夾與不可變交接紀錄流程。
2. 將 M0 角色順序固定為：PM → 世界觀 → UI → 建模 → 工程 → QA。
3. 確認 MVP 範圍：iOS／Android 直式、單手拖曳、自動射擊、三章、3 Boss、24 一般能力、12 Boss 獎勵、6 項永久升級、離線與 checkpoint 恢復。
4. 確認非範圍：多人、帳號／雲端、廣告、內購、推播、LiveOps、裝備背包。
5. 確認 M1 前不可取消的風險驗證：單手操作、Gate 防雙選、Boss Reward idempotency、存檔／前後台、Low／Standard 裝置效能。
