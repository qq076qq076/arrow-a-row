# M3-ENG-009：戰鬥節奏與 Boss 進場

狀態：Completed｜角色：工程師｜Milestone：M3 系統完成｜完成日期：2026-07-29｜Commit：`工程(M3)：調整戰鬥節奏與Boss進場`（以 Git history 的最終 hash 為準）

## 輸入

- 使用者調整需求：鏡頭仰角約 30°、Boss 必須由遠處走近、Boss 前須有 4–6 波小怪、開始遊戲即射箭。
- [M3-ENG-008](M3-ENG-008-擴充GateBuff.md)：現行 Gate Buff 與六章連續 Run 基線。

## 已完成產出

- 相機由前方低角度改為約 30° 向下觀看，保留橫向跟隨與遠方道路可視範圍。
- 每章在 15、24、35、38、48 公尺配置五組小怪；56 公尺才生成 Boss。
- Boss 初始於 z=46，移動至戰鬥位置 z=15 才開始攻擊；渲染位置直接同步模擬座標，畫面可見其走近。
- 遊戲首個 tick 即建立箭矢，即使尚未有目標也能看出自動射擊節奏，協助玩家辨識箭數與箭速 Buff 的效果。
- 近戰敵人僅在橫向命中範圍內造成傷害，使橫向移動具有迴避意義。
- 增加回歸測試，覆蓋立即射箭、Boss 出現門檻及其遠距走近至戰鬥位置。
