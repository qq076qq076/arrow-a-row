# M5-ENG-003：飛劍替換為自動電擊

狀態：Completed｜角色：工程師｜Milestone：M5 Beta／平衡與相容性｜完成日期：2026-07-29｜Commit：`工程(M5)：以自動電擊取代飛劍`（以 Git history 的最終 hash 為準）

## 產出

- 移除飛劍 Buff、飛劍回響、飛劍 HUD 與相關圖示／本地化字串。
- 新增自動電擊：起始每秒鎖定前方、鎖定距離內最近兩個敵人並造成每秒傷害；已越過玩家的敵人立即失去鎖定，改由最近前方目標補上。
- Boss 位於鎖定距離內時可佔用一個電擊目標，避免電擊 Build 在 Boss 戰失效。
- 新增三種 Buff：`lightning_targets`（鎖定數）、`lightning_damage`（每秒傷害）、`lightning_range`（鎖定距離）；Boss 回響改為雷網核心，同時強化三項屬性。
- Three.js 以脈衝電光晶體標示目前鎖定目標，HUD 顯示目標數、每秒傷害與距離。
- 既有 checkpoint 的飛劍 Buff／回響會在恢復時遷移為電擊目標／雷網核心。
