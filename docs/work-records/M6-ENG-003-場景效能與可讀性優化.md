# M6-ENG-003：場景效能與可讀性優化

狀態：Completed｜角色：工程師｜Milestone：M6 關卡節奏重整｜完成日期：2026-07-30

## 需求

- 同一畫面允許更多怪物、掉落物與特效同時存在，降低卡頓。
- 怪物與寶箱固定朝向，不再持續旋轉。
- 怪物血條加粗，提高大量敵人同場時的可讀性。

## 實作

- React HUD 更新節流至每秒 15 次；Three.js 仍維持畫面更新，避免每個畫格重建 HUD。
- 靜態場景、Gate、怪物、箭矢、命中效果與拾取物只在 simulation snapshot 改變時同步；閃電與 Boss 預警特效仍可每畫格動畫。
- 怪物模型、箭矢、命中效果與拾取物加入回收池，降低生成、銷毀與 GC 抖動；敵人模型依章節／種類分池重用。
- 敵人模型不再為每隻個體建立 PointLight，改使用既有材質色彩；同類模型共享材質，減少 GPU state change。
- 移除怪物與 Treasure Chest 的每畫格旋轉；怪物血條由 `1.15 × 0.12` 背景條與 `1.07 × 0.08` 填充條組成。

- `npm run build`：production build passed；保留既有 Vite chunk size warning。
- 模型用途：Gate 使用 Lantern 01，地面掉落使用 Treasure Chest；模型來源記錄於 `docs/assets/PolyHaven-來源與授權.md`。
