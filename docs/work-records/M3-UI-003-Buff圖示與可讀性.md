# M3-UI-003：Buff 圖示與可讀性

狀態：Completed｜角色：介面設計師／工程師｜Milestone：M3 系統完成｜完成日期：2026-07-29｜Commit：`介面(M3)：放大Buff文字並加入圖示`（以 Git history 的最終 hash 為準）

## 輸入

- 使用者需求：增大路上 Buff 文字說明，並在上方放置對應 icon 方便辨識。

## 已完成產出

- 掉落 Buff 3D 說明牌由 1024×192 提高為 1024×420，文字改為 108px 並提高世界顯示尺寸。
- 每張牌文字上方加入高對比圓形圖示，對應箭矢、箭傷、箭速、射速、穿透、飛劍、生命、移速、減傷九種 Buff。
- 圖示與文字使用同一張 CanvasTexture，隨掉落物一起行進、面向鏡頭，且替換／釋放時仍正確處理貼圖資源。
