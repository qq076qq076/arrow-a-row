# M5-ENG-020：弓箭手玩家模型與電擊距離

## 輸入

- 使用者要求：搜尋免費弓箭手模型替換玩家角色。
- 使用者要求：電擊初始鎖定距離改為 1 單位。
- 既有 Three.js 玩家模型載入與 M1 電擊鎖定規則。

## 產出

- 下載 Poly Pizza 的 Archer GLB，放入 `public/assets/poly-pizza/archer/archer.glb`。
- 玩家角色改用弓箭手模型，並調整縮放、錨點位置與材質深度排序，避免服裝閃爍。
- 新遊戲與缺少欄位的舊存檔，電擊初始距離為 1；電擊強化仍可增加距離。
- 保留模型來源與 CC BY 3.0 授權於模型旁 README 與資產授權總表。

## 完成標準與證據

- `npm test -- --run` 通過。
- `npm run build` 通過。
- `npm run test:e2e` 通過。
- 本地遊戲畫面可見完整弓箭手、Build HUD 顯示「⚡ 1 距離」，且瀏覽器 console 無 error／warning。

## 風險與交接

- Poly Pizza 資產採 CC BY 3.0，任何再發布仍須保留作者與來源連結。
- 模型為靜態 GLB；玩家位移由外部 anchor 驅動，後續若要加入拉弓動畫，應另接動畫 clip 或替換為帶 rig 的同授權資產。
