# M5-ENG-023：再次修正左右移動方向

狀態：Completed｜角色：工程師｜Milestone：M5 Beta／平衡與相容性

## 問題

玩家模型改為固定世界座標取景後，畫面上的左右方向與滑鼠／觸控操作再次相反。Three.js 鏡頭位於路徑起點、朝正前方觀察時，世界 X 軸的正方向投影到畫面左側，因此直接將螢幕 X 映射為世界 X 會顛倒操作。

## 修正

`App.tsx` 的滑鼠與觸控共用座標換算改為反向映射：畫面左側對應玩家世界座標 `+5`，畫面右側對應 `-5`，與目前固定鏡頭投影一致。兩種輸入仍透過同一個 `movePlayerFromClientX` 入口，避免行為分歧。

- TypeScript／Vite production build：通過
