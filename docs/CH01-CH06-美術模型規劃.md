# CH01–CH06 六類模型美術規劃

日期：2026-07-29  
用途：作為逐章模型替換、免費資產挑選、尺寸與光線調校的唯一設計依據。

## 共通規則

六類模型均須在每一章可辨識，且同一 Buff 類型使用同一個模型語言：

| 類別 | 共通視覺規則 |
| --- | --- |
| 玩家 | 統一使用同一名「光軌行者」角色；僅調整章節輪廓光與貼圖色溫。 |
| 小怪 | 近戰採重、矮、前傾剪影；遠程採高、懸浮或有炮口／發光核心的剪影。 |
| Boss | 比玩家高 2.2–2.8 倍、有明確核心、蓄力時核心發光；每章不可重複。 |
| 道路 | 可重複拼接模型；邊緣、材質與輪廓須能表明章節地貌。 |
| 街景 | 至少兩種側景物，以 12–16m 節距交錯；不進入主要三條路徑。 |
| Buff | 固定使用燈籠／核心容器模型；以顏色、符號與點光區分能力，不改變幾何語言。 |

## 實作順序

1. 先完成每章 Boss、道路、街景，確立一眼可辨識的章節主題。
2. 再替換近／遠小怪並設定章節色彩與攻擊讀取。
3. 玩家與 Buff 維持共用模型，只調整輪廓光、材質與大小。
4. 每章需通過實機畫面檢查、來源／授權登錄、建置／測試後才可獨立提交。
