# CH01–CH06 六類模型與背景元素美術規劃

日期：2026-07-30
用途：作為逐章模型替換、背景元素配置、免費資產挑選、尺寸與光線調校的唯一設計依據。

## 共通規則

六類模型均須在每一章可辨識，且同一 Buff 類型使用同一個模型語言：

| 類別 | 共通視覺規則 |
| --- | --- |
| 玩家 | 統一使用同一名「光軌行者」角色；僅調整章節輪廓光與貼圖色溫。 |
| 小怪 | 近戰採重、矮、前傾剪影；遠程採高、懸浮或有炮口／發光核心的剪影。 |
| Boss | 比玩家高 2.2–2.8 倍、有明確核心、蓄力時核心發光；每章不可重複。 |
| 道路 | 可重複拼接模型；邊緣、材質與輪廓須能表明章節地貌。 |
| 背景元素 | 每章至少 5 種可辨識元素；道路是基底，不列入 5 種；近、中、遠景至少各有一層。 |
| 側景 | 以 12–16m 節距交錯，同類元素不可連續重複；不進入主要三條路徑。 |
| 氛圍層 | 霧、火星、孢子、星圖或裂光等效果只做低密度背景，不遮住玩家、敵人、投射物與 Gate。 |
| Buff | Gate 使用 Lantern 01；小怪掉落使用 Treasure Chest。兩者以顏色、符號與點光區分能力，讓 Gate 與地面拾取物有清楚的形狀差異。 |

## 背景元素規劃（設計師交付）

本節是每章背景的最低交付，不把小怪、Boss、Gate 或 Buff 算作背景元素。每章需完成「道路基底 + 至少 5 種背景元素」，並依近景、中景、遠景分層，讓玩家在直式鏡頭下能用輪廓與色塊辨識章節。

### 共用配置規則

- 近景放在道路外側約 `x = ±6.2–8.2`、距離 `z = 8–20m`；只放低矮或不遮擋的元素。
- 中景放在 `x = ±7.0–10.0`、距離 `z = 20–56m`；用兩種主題道具交錯建立節奏。
- 遠景以地平線、天空投影或低密度粒子表現；不得與敵人、Boss 預警色混淆。
- 每 12–16m 至少出現一個章節識別元素，左右側交替；不要在同一個 z 節點堆滿道具。
- 所有背景元素均為裝飾，不參與碰撞、不改變路徑寬度；三條主要路徑保留清楚的負空間。

### CH01 晨線草原

1. **草坡土壤斷面（近景）**：道路兩側的青綠草坡露出赤褐土層，建立「晨線從土地重新流動」的基底；以短段落重複，不做可碰撞障礙。
2. **赤褐風化巨岩（中景）**：使用 `Rock 07` 作為視線節點，輪廓呼應苔冠守衛的石像身體；左右交錯，避免連續四個波次都出現相同朝向。
3. **低草與晨露花簇（近景）**：以低模草叢、金色露珠點光補足道路邊緣，色彩比 Gate 暗，避免玩家把裝飾誤認為 Buff。
4. **木製風向旗／舊路標（中景）**：用布片與弧形箭頭指向前方，將風與「箭只往正前方射出」的玩法提示連起來；Boss 前段可安排一支較大的破損路標作地標。
5. **晨霧山脊與金色光軌（遠景／氛圍）**：地平線用低對比山脊、薄霧和斜向金光收束畫面，讓玩家感覺道路通往更遠處，而不是跑在無限綠色平面。

### CH02 鏡潮高架

1. **藍鋼高架護欄與斷裂接縫（近景）**：用冷色金屬邊框明確定義高架邊界；斷裂處只做視覺缺口，不能形成可跌落或改道判定。
2. **Street Lamp 01 冷光路燈（中景）**：既有 `Street Lamp 01` 作為節拍燈塔，每 14m 左右交替一盞，冰藍點光提示鏡潮的能源流向。
3. **Power Box 01 配電節點（中景）**：既有 `Power Box 01` 放在路燈之間，與校準者的電磁核心形成同源語彙；不與路燈同一節點重疊。
4. **懸掛電纜與鏡面接點（中景／高位）**：從護欄外側跨接到遠方支架，使用細長斜線增加速度感；只保留高位輪廓，不穿過玩家與敵人可讀區。
5. **鏡潮水汽與遠方反射塔（遠景／氛圍）**：以低透明度水霧、倒影藍帶和破碎塔影表現「高架漂在鏡面潮汐上」，不使用高反射材質以控制手機效能。

### CH03 熾心熔庭

1. **玄武岩板道與熔裂邊緣（近景）**：道路基底改為暗紅玄武岩，裂縫露出橙光；裂縫只作材質與點光，不生成傷害區，傷害預警仍由獨立 VFX 負責。
2. **炭火桶／Barrel 01（中景）**：既有 `Barrel 01` 作為熔庭的燃料容器，三個段落配置即可形成辨識點；只保留少量火光，避免與敵彈同色。
3. **Modular Industrial Pipes 01 管線（中景／高位）**：既有管線沿道路外側向前延伸，讓玩家理解熔庭是仍在運作的鍛造設施；管線不得越過三條路徑上方。
4. **熔脈通風口與爐壁拱門（中景）**：以短拱門、排氣口、鉚釘金屬板串起鍛爐空間，Boss 前方可用一組較大的拱門作熔脈監工登場框景。
5. **煙塵、火星與遠方熔流（遠景／氛圍）**：煙塵保持紫紅低對比，火星只在道路兩側緩慢上升；遠方熔流以橙色水平光帶暗示熱源，不遮蓋範圍預警。

### CH04 霧冠林海

1. **苔石樹根棧道（近景）**：道路邊緣改成被根系托起的苔石，讓「霧冠」不是一般平地森林；根面需要保留明亮輪廓，避免和玩家影子混成一團。
2. **Tree Small 02 扭曲樹冠（中景）**：既有 `Tree Small 02` 形成左右兩側的高大剪影，枝葉上緣留出霧白天空，避免完全封閉視線。
3. **Pine Roots 盤結根系（近景／中景）**：既有 `Pine Roots` 以斜向根系穿出土坡，與樹冠形成上下呼應；根系不得伸入敵人生成區。
4. **Tree Stump 01 孢囊樹樁（近景）**：既有 `Tree Stump 01` 可同時作小怪形狀參考與背景變體；背景樹樁要更低、更寬，不能與孢囊衝撞獸混淆。
5. **垂掛藤蔓、孢子簇與霧幕（遠景／氛圍）**：以少量青色孢子點和分段霧幕營造遮蔽，但任何霧幕連續遮擋主角或投射物不得超過 1 秒。

### CH05 星圖遺庫

1. **靛藍典藏地板與金線導軌（近景）**：道路基底像被改造的書庫地板，金線沿前進方向延伸，將安全縫與星圖閱讀方向連起來。
2. **Shelf 01 遠近書架（中景）**：既有 `Shelf 01` 作為主要垂直節奏，書架只靠道路外側，保留窄安全縫的視覺邊界，不壓縮實際路徑。
3. **School Desk 01 抄錄桌（近景）**：既有 `School Desk 01` 作為低矮側景，桌面可放發光紙張或空白卷軸；與抄錄傀儡的敵人剪影要用不同高度區分。
4. **Marble Bust 01 典藏雕像（中景）**：既有 `Marble Bust 01` 作為稀有地標，金色輪廓光呼應無光抄錄者的石質學者核心；Boss 前最多放一座，避免搶走 Boss 注意力。
5. **星圖投影與懸浮書頁（遠景／氛圍）**：用低密度星座線、圓形星圖和少量懸浮書頁填補深靛天空，所有文字／符號只做裝飾，不與 HUD 搶資訊層級。

### CH06 裂光地平

1. **紫黑浮島晶板（近景）**：道路基底由浮空晶板組成，邊緣以白金裂線標示「地平正在分裂」；晶板不做實際掉落機制，避免背景影響終局操作。
2. **斷裂浮島碎片（中景）**：道路兩側配置不同大小的懸浮平台與碎片，沿前進方向有明顯遠近縮放，形成最終章的空間失重感。
3. **Modular Industrial Pipes 能量錨（中景）**：既有 `Modular Industrial Pipes 01` 改為白金／紫色能量錨，固定在浮島外緣；它是 CH06 與前面工業元素的回收呼應。
4. **訊號塔／Radio Array（中景／高位）**：以 `Vintage Radio Transceiver` 的天線語彙延伸成遠方訊號塔，指向靜滯之核；Boss 本體保留獨一個放大訊號核，背景塔不使用相同亮度。
5. **白金裂縫、雷暴與地平光帶（遠景／氛圍）**：遠景以低密度裂光、紫黑雷雲和水平白金光帶收束六章色彩；雷電只能在畫面外緣或高位閃現，不蓋住終局預警環。

### 背景元素交付與驗收

1. 每章提交道路基底與至少 5 種背景元素的 `asset ID`、參考圖、色票、比例、近／中／遠景標籤及建議 z 節點。
2. 已有資產優先沿用；新增模型需補上來源／授權、GLB 或程序化替代方案、LOD 與手機效能預算。
3. 1080×1920 直式畫面中，背景元素必須能在縮小後以輪廓或色塊辨識；Low 畫質仍保留每章的主色與兩個識別地標。
4. 背景不遮住玩家、敵人、投射物、Gate、Boss 核心與預警環；不增加碰撞、不改變三條路徑、不製造需要玩家反應的假訊號。
5. 每章至少安排一次「遠景地標 → 中景道具 → 近景材質」的連續讀景，讓玩家在 15 波戰鬥與 Boss 區段中感覺確實穿越同一個場所。

## 實作順序

1. 先完成每章 Boss、道路、街景，確立一眼可辨識的章節主題。
2. 再替換近／遠小怪並設定章節色彩與攻擊讀取。
3. 玩家與 Gate Buff 維持既有模型語言；地面掉落 Buff 使用 Treasure Chest，並只調整輪廓光、材質與大小。
4. 每章需通過實機畫面檢查、來源／授權登錄、建置／測試後才可獨立提交。
