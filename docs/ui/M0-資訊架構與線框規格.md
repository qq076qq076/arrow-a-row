# M0：手機資訊架構與低保真線框規格

版本：0.1｜Owner：介面設計師｜基準：1080×1920、9:16 直式｜關聯：[畫面流程與 UI 規格](../Arrow-a-Row-畫面流程與UI規格.md)、[第一章文案](../content/localization_narrative.csv)

## 1. 螢幕地圖

```text
S-01 啟動 → S-02 主選單 → S-03 載入 → R-01 教學／R-02 Run
                 ├→ S-04 商店
                 ├→ S-05 成就（M2 後）
                 └→ S-06 設定
R-02 → R-03 暫停 → R-04 Build 詳情／S-06 設定
R-02 → R-05 Boss Reward → R-02 下一章
R-02 → R-06 死亡結算／R-07 勝利結算 → S-02／S-04／S-03
任意 Run → 系統中斷 → R-03（已自動暫停）
```

M0 只需設計 S-02、S-03、R-01/R-02、R-03、R-05、R-06、S-04；其他畫面沿用元件規則，可在 M2 完成。

## 2. 直式安全區與手勢規則

| 區域 | 尺寸／規則 | 可放內容 |
| --- | --- | --- |
| Top safe area | 依裝置動態 inset，另留 16dp | 僅 HUD 資訊；不可放關鍵 CTA。 |
| Bottom safe area | 依手勢列 inset，另留 16dp | Build 快覽；不可放拖曳必經區。 |
| 左右邊界 | 16dp 內距 | 非關鍵裝飾；Gate 不得裁切。 |
| 拖曳主區 | 畫面中下 65%，扣除 UI 命中區 | 水平拖曳移動；不可放可點卡片。 |
| 暫停命中區 | 左上 safe area 下方，48×48dp | 開 R-03。 |
| Build 命中區 | 右上 safe area 下方，48×48dp | 開 R-04。 |

UI 元件先攔截 touch。當觸點起點落在 UI、捲動容器或 safe-area 保留區，該次 touch 絕不能驅動角色。Overlay 關閉後必須重新觸碰才能移動。

## 3. 關鍵畫面線框

### S-02 主選單

```text
┌────────────────────────────┐
│        [遊戲標誌]           │
│  晨線草原／主角低動態背景   │
│        金幣：000             │
│                              │
│      [ 開始新局 ]            │  52dp CTA
│      [ 商店 ]                │
│      [ 成就 ] [ 設定 ]       │
│                              │
│  最近：最高分／最遠章節      │
└────────────────────────────┘
```

有 checkpoint 時主要 CTA 改為 `繼續本局`，下方顯示章節、HP、保存時間；`放棄本局` 為文字次要操作，距主 CTA 至少 24dp，必需二次確認。

### R-02 跑圖 HUD

```text
┌────────────────────────────┐
│ [Ⅱ] HP 82/100      [Build] │
│          第 1 章 · 52%      │
│                分數 230 金 4│
│                              │
│        左 Gate   右 Gate    │
│       +1 箭矢   回復 25 HP  │
│                              │
│          （世界／戰鬥）      │
│                              │
│    [弓 2] [飛劍 1] [盾 1]    │
└────────────────────────────┘
```

Gate 字體最少 20sp，效果最少 18sp；卡片／門有不透明或半不透明底。HP <30% 時血條、心形圖示與脈動外框同時提示。Boss 時中央進度列替換為 Boss 名稱與血條。

### R-05 Boss Reward

```text
┌────────────────────────────┐
│        首領已擊敗            │
│       選擇一份回響            │
│ [卡 A]  [卡 B]  [卡 C]       │
│  稀有    稀有    稀有         │
│  名稱    名稱    名稱         │
│  變化    變化    變化         │
│                              │
│ 金幣 7  [重擲（2）]           │
└────────────────────────────┘
```

三卡寬度相等、最小高度 260dp；一次 tap 展開／選取，第二次或 `選擇` CTA 確認。卡片細節用 bottom sheet，不能靠 hover。重擲不足金幣時顯示原因，不可只灰掉。

### R-06 結算

結果標題 → 分數／最遠章節／存活時間 → 金幣與新解鎖逐項數出 → `再來一局`（primary）、`前往商店`、`主選單`。死亡原因用 `localization_narrative.csv` 的 key；不得以紅色／失敗動畫延遲玩家重開超過 1.2 秒。

## 4. 元件與狀態矩陣

| 元件 | 必須狀態 | 規則 |
| --- | --- | --- |
| Primary button | default、pressed、disabled、loading | loading 時鎖定第二次點擊。 |
| Gate | default、readable、selected、disabled | selected 後另一門 150ms 內轉 disabled。 |
| Reward card | default、focused、expanded、confirmed、disabled | confirmed 不可逆，寫檔成功前顯示 loading。 |
| Shop item | locked、available、insufficient、purchasing、max | 不足時顯示差額。 |
| Toast／modal | info、error、blocking | blocking modal 有可行動文案與關閉／重試。 |

## 5. M0 UI 驗收

- 在 720×1280、1080×1920、瀏海／挖孔／手勢列圖框中，HUD、CTA、Gate 無裁切。
- 主選單到開始新局、HUD 到暫停、Boss Reward 到選卡均有唯一且可觸控的主流程。
- 文案 key 的最大字數可容納繁中與英文，不以縮小至不可讀字級解決。
- Gate 正負／稀有資訊不只靠色彩；一手持機下不會因點暫停／Build 啟動角色拖曳。
- 本線框可讓工程在沒有高保真素材時建立 M1／M2 UI shell。
