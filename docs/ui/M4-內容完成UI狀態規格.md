# M4：內容完成 UI 狀態規格

## 共通規則

- 直式手機優先；HUD、Build、Boss 條必須落在 safe area。
- 所有 Buff 用「圖示＋名稱＋數值」，不可只依顏色辨識。
- 繁中與英文各預留 1.5 倍字寬；不可把必要文字烘焙進 3D 貼圖以外的非本地化資產。

## 畫面狀態

| 畫面 | 必要內容 | 驗收 |
| --- | --- | --- |
| 主選單 | 六章解鎖、開始／繼續、商店、成就入口 | 44px 以上觸控目標，鎖定章節不可誤開。 |
| Run | HP、Build、距離／Boss、掉落 Buff 圖示、正前方瞄準教學 | Buff 文字不遮擋敵人預警；低寬度自動換行。 |
| 回響 | 三張隨機卡、圖示、效果、確認按鈕 | 未選不可確認；選取狀態非僅色彩。 |
| 商店 | 六項永久強化、金幣、購買成本、滿級狀態 | 重複點擊不重複扣款。 |
| 成就 | 12 格、鎖定提示、進度、已領取狀態 | 獎勵只能結算一次。 |
| 結果 | 金幣、章節完成、下一章／重開／商店 | 操作不遮擋 safe area。 |

## M4 UI 驗收

在 320px 寬至桌機橫式、Chrome Android／iOS Safari 模擬器，主選單、Run、回響、商店、成就、結果均有明確焦點、無裁切、無關鍵文字只靠色彩。
