# M2：第一章 Boss、Reward、商店與結算互動狀態規格

版本：0.1｜Owner：介面設計師｜關聯：[M2 世界觀交接](../work-records/M2-WORLD-001-第一章戰鬥與商店文案.md)

## Boss HUD

| 狀態 | 顯示 | 互動 |
| --- | --- | --- |
| Phase 1 | `苔冠守衛` HP 條、目前 HP／最大 HP | 不可遮蓋走位區。 |
| Telegraph | 招式 key 對應短句 + 黃色 icon + 進度環 | 0.6 秒內清楚可讀，不使用 blocking modal。 |
| Phase 2 | `靜滯正在加深！` 短句、HP 條切換 | 敵彈清除後顯示，0.8 秒後消失。 |
| Defeated | 清空敵彈、0.8 秒擊殺回饋 | 之後才開 Reward。 |

## Reward 三選一

三張卡使用左／中／右固定順序。第一次點按只選取並展開數值；第二次點同張或點 `選擇` 才確認。確認後全卡 disabled，顯示儲存中，成功才進下一畫面。重擲是底部 52dp CTA，顯示 `重擲（N 金幣）`；金幣不足顯示原因文字。

| card id | 顯示 key | 必顯示數值 |
| --- | --- | --- |
| `storm_bow` | `reward.storm_bow` | `箭數 +2`、`散布 -4°` |
| `blade_nexus` | `reward.blade_nexus` | `飛劍 +2`、`CD 2.2 秒` |
| `heartwood` | `reward.heartwood` | `最大 HP +60`、`減傷 +8%` |

## 商店與結算

- 結算：標題、分數、`result.gold`、新餘額、`再來一局`／`前往商店`／`主選單`。
- 商店：頂部金幣餘額；三張商品卡含目前級、下一級、成本；購買後先 disabled，等 IndexedDB 成功才更新。
- 錯誤：儲存失敗顯示 `error.save_failed` toast；不得假裝升級成功。

## 驗收

直式 safe-area 下所有 CTA ≥48dp；Boss 預警可在 720×1280 讀到；Reward 不可誤選；商店餘額／等級不因重複 tap 改兩次；繁中／英文不截字。
