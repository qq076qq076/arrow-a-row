# Arrow a Row：畫面流程與 UI 規格

版本：0.2｜2026-07-28｜平台：iOS／Android 手機優先｜關聯文件：[遊戲開發規格書](Arrow-a-Row-開發規格書.md)

本文件定義遊戲內每個獨立畫面／Overlay 的資訊、互動、轉場、資料讀寫與驗收要求。名稱與美術均應原創；以下使用「主角」、「飛劍」、「夥伴」等功能性名詞，不構成既有作品資產規格。

## 1. 全域畫面規則

### 1.1 畫面分類

| 類別 | 畫面 | 是否暫停遊戲 | 是否可返回 |
| --- | --- | --- | --- |
| Shell | 啟動、主選單、商店、設定、成就 | 不適用 | 除啟動外皆可。 |
| Run HUD | 教學、一般跑圖、Boss 戰 | 否 | 不適用。 |
| Run Overlay | 暫停、能力詳情、Boss 獎勵、結算 | 依畫面而定 | 規格定義。 |
| 系統 | 確認離開、錯誤、資料修復、載入 | 依情況 | 防止誤操作。 |

- 主要設計基準為 1080×1920、9:16 直式；最低 720×1280。支援 16:9、18:9、19.5:9、20:9；平板與橫式只重排 HUD／延展背景，不改變遊戲規則。
- 所有 UI 使用裝置 safe area；瀏海、Dynamic Island、挖孔、圓角與系統手勢區不可放 CTA、金幣、HP、Gate 核心文字。
- 所有觸控目標最小 48×48 dp、主要 CTA 最小高度 52 dp、相鄰可點目標間距至少 8 dp；滑鼠 hover、鍵盤 focus、手把 selection 為 PC 延伸支援。
- 主要 CTA 使用同一色階；危險動作（刪檔、離開未結算 run）使用警示色與二次確認。
- 繁中為第一語言，英文為必要語言。按鈕文字不小於 16 px，核心 HUD 不小於 18 px。
- Android 系統返回：Shell 回上一層；Run 一律開 R-03 暫停，禁止直接離局。iOS 無系統返回鍵，左上返回控制維持同一行為。
- Run 的非 UI 區域接收單手水平拖曳；UI 預先攔截觸控。手指落在按鈕、卡片、捲動區或 safe-area 保留區時，絕不能移動角色。

### 1.2 轉場規格

| 轉場 | 時間 | 規則 |
| --- | ---: | --- |
| Shell → Shell | 180–250 ms | 淡入淡出或內容滑動；禁止閃白。 |
| 開始新局 | 最多 3.5 s | 手機顯示載入進度與提示；完成才可輸入。 |
| 穿過選擇門 | 150 ms lock | 顯示門選中回饋並禁用另一路。 |
| Boss 死亡 → 獎勵 | 0.8–1.5 s | 清彈、擊殺演出、再開獎勵；中途不可跳過。 |
| 結算 | 0.5–1.2 s | 先顯示結果，再依序數出分數、金幣、解鎖。 |

## 2. 畫面流程圖

```text
[啟動] → [主選單] ───────→ [商店] ──→ [主選單]
                ├────────→ [成就] ──→ [主選單]
                ├────────→ [設定] ──→ [主選單]
                ├─ 有局內檔 → [繼續本局] → [Run HUD]
                └─ 開始新局 → [載入] → [教學／Run HUD]

[Run HUD] → [暫停] → [Run HUD]
    ├────→ [能力詳情] → [Run HUD]
    ├────→ [Boss 獎勵] → [Run HUD：下一章]
    ├────→ [死亡結算] → [主選單／商店／再來一局]
    └────→ [勝利結算] → [無盡模式／主選單／再來一局]

任何畫面 ──（鎖屏／來電／切後台）──→ [自動暫停＋Checkpoint]
      └────────────────────（回前景）→ [R-03 暫停選單]
```

## 3. Shell 畫面

### S-01 啟動畫面與資料載入

| 項目 | 規格 |
| --- | --- |
| 目的 | 初始化設定、存檔、內容版本與音訊，避免玩家在資料未就緒時操作。 |
| 視覺 | 原創工作室／遊戲標誌、循環背景、進度條或旋轉指示器。不可展示參考作品素材。 |
| 內容 | `正在載入…`、版本號、隱私／無障礙快捷鍵（可選）。 |
| 進入 | 應用程式啟動、返回主選單時內容熱重載。 |
| 離開 | Profile、內容資料與必要音效初始化成功後自動到 S-02。 |
| 例外 | 存檔讀取失敗時開 S-12 資料修復，不可無提示覆蓋檔案。 |
| 驗收 | Standard 目標機冷啟動到可互動主選單 ≤5 秒、Low 目標機 ≤8 秒；載入期間重複點擊不產生多重場景。 |

### S-02 主選單

**目的**：顯示目前進度，提供所有高頻入口。

| 區域 | 內容／行為 |
| --- | --- |
| 背景 | 低動態、原創場景／主角 idle。必須低於按鈕對比優先度，並可在設定降低動態。 |
| 標題區 | 遊戲標誌、目前版本、小型公告（可選，離線時不顯示錯誤）。 |
| 主要 CTA | `開始新局`；有未結算 checkpoint 時改為 `繼續本局` 並顯示章節、HP、經過時間。 |
| 次要 CTA | `商店`、`成就`、`設定`。手機版移除 `離開遊戲`；讓 OS 管理退出。 |
| 進度摘要 | 金幣餘額、最高分、最遠章節、最近一次 Run 結果。 |
| 未完成 Run | 同時提供小型 `放棄本局`；點擊後必須開 S-11 二次確認。 |

手機操作：整張 CTA 可點；有未完成 Run 時 `放棄本局` 與 `繼續本局` 必須相距至少 24 dp，且放棄為次級樣式。PC 版輸入順序：開始／繼續 → 商店 → 成就 → 設定 → 離開。無未完成 Run 時，`開始新局` 建立 seed、初始化 Run，進 S-03。

驗收：首次啟動能看見開始新局與 0 金幣；有 checkpoint 時 100% 顯示繼續入口；不會因焦點遺失使鍵盤按 Enter 直接離開遊戲。

### S-03 新局載入

| 項目 | 規格 |
| --- | --- |
| 內容 | 載入進度、隨機遊玩提示、取消按鈕（尚未進入 simulation 前才可取消）。 |
| 資料 | 建立 `runId`、seed、內容版本，複製永久升級至初始 PlayerStats。 |
| 成功 | 首次進入時顯示 R-01 教學；其後進 R-02 一般跑圖。 |
| 失敗 | 顯示重試／返回主選單；不得遺失既有 Profile 金幣。 |
| 驗收 | 同一次點擊不會建立兩個 Run；取消不留下可繼續的空白 checkpoint。 |

### S-04 商店

**目的**：使用局外金幣購買永久升級，並讓玩家理解「發現能力 → 解鎖商店項目」的循環。

| 區域 | 內容／互動 |
| --- | --- |
| 頂列 | 返回、標題 `永久強化`、金幣圖示與餘額。 |
| 分類列 | 基礎、弓箭、飛劍、夥伴、生存；未解鎖分類仍顯示但以鎖頭標註。 |
| 商品卡 | 圖示、名稱、目前 Lv、下一級效果、成本、最大等級、解鎖提示。 |
| 詳情面板 | 點選卡片後顯示所有級別、目前值→下級值、能力首次在 Run 中出現的解鎖條件。 |
| 購買按鈕 | `購買（N 金幣）`；不足時禁用並提示差額；滿級改 `已滿級`。 |
| 回饋 | 成功時卡片升級、餘額動畫、SFX；寫檔成功才顯示完成。 |

購買流程：選卡 → 檢查餘額與最大級 → 寫入交易 → 更新 Profile → 成功回饋。若寫入失敗，餘額與等級回復原值並顯示 S-13 錯誤提示。

驗收：不可購買未發現項目、不可負金、重啟後等級與餘額一致；手機上分類可水平捲動、商品清單垂直捲動，捲動與點擊購買不衝突。

### S-05 成就與圖鑑

| 區域 | 內容 |
| --- | --- |
| 頂列 | 返回、完成數 `N / Total`、篩選（全部／進行中／已完成／隱藏）。 |
| 成就清單 | 圖示、名稱、描述、進度、獎勵（金幣或外觀）；未公開成就顯示模糊提示，非空白。 |
| 詳情 | 條件、目前進度、完成時間、領取狀態。若獎勵需手動領取，顯示 `領取`。 |
| 能力圖鑑（可選） | 已發現能力的效果、稀有度、最大層數；不顯示尚未發現的精確數值。 |

驗收：同一成就獎勵只能領一次；Run 中達成後在結算正確更新；篩選不遺失焦點。

### S-06 設定

| 分頁 | 控制項 |
| --- | --- |
| 音訊 | 主、音樂、效果音音量（0–100）、靜音。 |
| 畫面 | 30／60 FPS、畫質、降低特效、降低背景動態、UI Scale、低電量模式。PC 延伸支援全螢幕、解析度、VSync。 |
| 操作 | 拖曳／左右半屏模式、拖曳靈敏度、觸覺回饋；PC 延伸支援鍵盤／手把重綁。 |
| 可近用性 | 色弱高對比門色、減少鏡頭震動、傷害數字、字幕、字級。 |
| 遊戲 | 教學重看、清除 Run checkpoint（需確認）、顯示 seed／debug（僅開發版）。 |

設定即時套用且寫入 Profile。修改解析度／全螢幕後保留 10 秒 `保留變更` 倒數，未確認或螢幕不可用則回復。

### S-07 離開遊戲

手機版不提供離開按鈕；系統將 App 切後台時自動暫停與保存。PC 版從主選單點選：若無 Run，直接正常退出；若有 Run，開 S-11，提供 `儲存並離開`、`放棄本局`、`取消`。

## 4. Run HUD 與遊戲中畫面

### R-01 首局教學 HUD

R-01 沿用 R-02 的 HUD，加上不可錯過、逐步消失的教學提示。不要用全螢幕彈窗阻擋第一次走位。

| 步驟 | 畫面額外內容 | 結束條件 |
| --- | --- | --- |
| 移動 | 角色左右各一個方向鍵提示、短句「左右移動」。 | 有效移動 0.5 秒。 |
| 門 | 左右門上方箭頭與「選擇一個強化」。 | 選定門。 |
| 自動攻擊 | 目標框、箭飛行軌跡提示「自動攻擊前方敵人」。 | 擊殺一隻。 |
| 躲避 | 投射物預警標記、提示「左右避開」。 | 離開戰鬥區。 |
| 獎勵 | 進 R-05，額外標記「選一個，打造 Build」。 | 選擇獎勵。 |

可用設定關閉教學提示，但首局的安全數值與固定選項仍保留。每一步只一條訊息；完成後淡出 250 ms。

### R-02 一般跑圖 HUD

| 位置 | 元件 | 規格 |
| --- | --- | --- |
| 左上 | 玩家 HP | 數字 `HP / Max HP` + 條；低於 30% 加警示外框和脈動，不只變紅。 |
| 上中 | 章節／進度 | `第 N 章` 與 0–100% 路段進度；非 Boss 時不顯示 Boss 條。 |
| 右上 | 分數、金幣 | 分數即時累積；金幣變化顯示 `+N`，不遮擋畫面。 |
| 下中 | Build 快覽 | 弓箭、飛劍、夥伴、生存四個最多圖示＋層數；滿寬時橫向展開。 |
| 左下 | 暫停 | 48 dp 以上的 `Ⅱ` 按鈕；不可置於左／右拇指拖曳主區。PC 顯示 `Esc / Menu` 提示。 |
| 場景前方 | Gate／敵人資訊 | 兩門名稱、圖示、效果、稀有度與負面／戰鬥風險均要高對比可讀。 |

互動：以單手在非 UI 區水平拖曳移動。右上／左下各提供 48 dp 按鈕開 R-04 與 R-03；PC 可用 `Tab`／`Esc`。手指抬起後角色立即煞停；關閉任何 Overlay 後，必須重新按下／拖曳才可移動，避免意外撞彈。

### R-03 暫停選單

開啟後完全停止 simulation、計時、投射物與敵方 AI。背景使用 60–75% 暗化，不可讓玩家誤以為仍會受傷。Android 返回鍵與 iOS 暫停按鈕都開此畫面。

| 按鈕 | 行為 |
| --- | --- |
| 繼續 | 關閉 Overlay；等待 0.15 秒後恢復輸入。 |
| 本局 Build | 開 R-04。 |
| 設定 | 開 S-06 子頁，返回應回 R-03。 |
| 回到主選單 | 開 S-11，確認後寫 checkpoint 並回 S-02。 |
| 放棄本局 | 開 S-11，確認後刪除 Run checkpoint、進 R-06 結算（結果為放棄）。 |

驗收：暫停超過 10 分鐘後 HP、敵方位置、射擊冷卻均不變；暫停／恢復連按不造成時間縮放錯誤。

### R-04 本局 Build 詳情

| 區域 | 內容 |
| --- | --- |
| 頂部摘要 | 目前章節、分數、seed（預設隱藏，可在進階設定開啟）。 |
| 左欄屬性 | HP、箭傷、箭數、攻速、暴擊、穿透、射程、減傷、吸血、移速；要顯示最終值與主要來源。 |
| 右欄能力 | 按弓箭／飛劍／夥伴／生存分組；每項含圖示、層數、短說明、下層可能效果。 |
| 底部 | `返回遊戲`、觸控提示；PC 額外顯示鍵盤與手把提示。 |

手機版一律**暫停**，防止單手開面板時誤觸與視線中斷；PC 可選快速查閱不停時，但需明確標示 `遊戲進行中`。

### R-05 Boss 獎勵選擇

進入前先清除敵對投射物與一般敵人；本畫面一律暫停 simulation。

| 區域 | 內容／規則 |
| --- | --- |
| 頂部 | `首領已擊敗`、章節、下一章提示、目前金幣。 |
| 中央三卡 | 三張不同能力卡：稀有度、圖示、名稱、目前層數→取得後層數、精確數值變化、短敘述。 |
| 重擲列 | `重擲（N 金幣）`、已重擲次數；不足金幣禁用。 |
| 詳情提示 | hover／focus 顯示完整 tooltip、與現有能力的相容／互斥。 |
| 無障礙 | 三卡固定左→中→右 focus；不得要求滑鼠 hover 才能讀到關鍵數值。 |

行為：卡片全區可點；先點一次可展開詳情、再次點同卡或點 `選擇` 才確認，避免拇指誤選。選定後立即鎖卡，寫入 checkpoint，套用 modifier，再轉下一章；重擲替換全三張，不可回退。若掉電後重啟，必恢復同一組候選或已鎖定的選擇，絕不可免費重抽。

驗收：連續點擊同一張只套用一次；互斥卡不出現；重擲造成金幣不足時按鈕狀態當幀更新。

### R-06 死亡結算

| 區域 | 內容 |
| --- | --- |
| 結果標題 | `本局結束`；放棄時明示 `已放棄本局`，不可偽裝為死亡。 |
| 主統計 | 分數、最遠章節、存活時間、擊殺數、Boss 擊殺數、最高 DPS（可選）。 |
| 報酬 | 本局金幣、成就獎勵、解鎖的新商店項目；逐項數出並更新總餘額。 |
| Death recap | 最後傷害來源、最後 3 個選擇、推薦方向（可選且不可誤導）。 |
| 行動 | `再來一局`、`前往商店`、`返回主選單`。 |

進入時先原子結算金幣與成就，再刪除／標記完成 Run checkpoint。按再來一局直接進 S-03；前往商店進 S-04；返回進 S-02。

驗收：結算多次開關不重複給金；死亡原因有 ID 對應的本地化文字；新解鎖商品立刻可在商店購買。

### R-07 勝利結算

沿用 R-06 的統計與報酬，另外顯示最終 Boss、通關時間、通關次數、解鎖項目。行動為：

| 按鈕 | 行為 |
| --- | --- |
| 進入無盡模式 | 僅在此 Run 提供；保留 Build，進入難度係數提高的下一章，先建立 checkpoint。 |
| 再來一局 | 結算完成後建立全新 Run。 |
| 商店／主選單 | 與 R-06 相同。 |

無盡模式按鈕應顯示風險（敵人 HP／傷害成長）與「通關結算已經完成」；玩家在無盡模式死亡不得重複發通關基礎獎勵。

### R-08 前後台恢復

| 情境 | 畫面行為 |
| --- | --- |
| App 切後台／鎖屏／來電 | 在當幀寫 checkpoint、靜音、停止 simulation；不得等到 OS 終止才保存。 |
| 回前景 | 直接開 R-03，標題加 `已自動暫停`；玩家選繼續後才恢復。 |
| OS 回收後重開 | S-02 顯示 `繼續本局`，並顯示最近保存時間。 |
| 在 R-05 獎勵中斷 | 返回 R-05 的同一批卡及相同重擲次數。 |

## 5. 系統畫面

### S-11 確認對話框

通用規則：標題直接說後果，確認按鈕採動詞而非模糊的「是」。焦點預設放 `取消`。

| 情境 | 文字 | 選項 |
| --- | --- | --- |
| 放棄 Run | `放棄這一局？未結算進度將遺失。` | 取消／放棄本局 |
| 返回主選單 | `儲存並回到主選單？可稍後繼續。` | 取消／儲存並返回 |
| 清除 checkpoint | `清除未完成本局？無法復原。` | 取消／清除本局 |
| 離開遊戲 | `要如何結束？` | 取消／儲存並離開／放棄本局 |

### S-12 資料修復

顯示「部分存檔無法讀取」，說明 Profile 或 Run 的類別、建立備份路徑（若平台允許），選項為 `嘗試修復`、`略過本局資料`、`返回桌面`。刪除／重建 Profile 是最後選項，必須輸入確認字串或長按 2 秒。

### S-13 錯誤與離線提示

非阻斷錯誤以右上 toast 顯示 4 秒，支援重試的阻斷錯誤改為 modal。文案需說明玩家可做什麼，例如：`無法儲存商店購買。未扣除金幣，請重試。` 不可只顯示錯誤碼；錯誤碼僅列在「詳細資料」。

## 6. 視覺狀態與文案規則

### 6.1 互動元件狀態

| 狀態 | 視覺 | 行為 |
| --- | --- | --- |
| Default | 正常色與標籤 | 可選。 |
| Hover / Focus | 外框、微亮、tooltip | 不能只靠亮度表示。 |
| Pressed | 80–120 ms 壓下 | 僅送一次命令。 |
| Disabled | 降低飽和＋原因文字 | 不接收互動。 |
| Locked | 鎖頭、條件 | 點選可閱讀解鎖方式。 |
| Selected | 勾選／框線 | 可被螢幕閱讀器讀出。 |

### 6.2 Gate 文案模板

| 類型 | 模板 | 範例 |
| --- | --- | --- |
| 直接增益 | `+{value} {stat}` | `+1 箭矢` |
| 百分比增益 | `{stat} +{value}%` | `攻速 +12%` |
| 即時生存 | `回復 {value} HP` | `回復 20 HP` |
| 風險獎勵 | `挑戰 {enemy}：獲得 {reward}` | `挑戰精英：獲得稀有能力` |
| 負面交換 | `{benefit}，但 {cost}` | `傷害 +50%，但最大 HP -20` |

門的正／負面不只用綠紅色；同時搭配 `+`／`−`、盾／劍／風險圖示與明確文字。
